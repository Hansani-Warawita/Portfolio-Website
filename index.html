My Projects

E-Commerce Website

Developed a responsive multi-page e-commerce website for Velvet Vogue, featuring product listings, category-based filtering, user and admin accounts, and a functional shopping cart with checkout. Designed to deliver a seamless, user-friendly shopping experience across all devices.

KickBlast Judo Application

Developed a C# GUI desktop application to calculate monthly training fees for athletes, featuring athlete registration, itemised cost breakdowns, weight category comparison, and scalable, well-structured design with input validation and error handling.

ETCP Mobile Application

Designed a high-fidelity Figma prototype for the Eco Tourism Cloud Platform (ETCP), focusing on intuitive user journeys that connect eco-travellers with sustainable tourism experiences. The prototype showcases core features such as eco-experience discovery, itinerary planning, and provider dashboards, with a user-centered, modern interface that emphasizes accessibility and sustainable tourism values.

Fresh Grocers Website

Designed a website prototype for Fresh Grocers, an online grocery delivery service in Sri Lanka, focusing on streamlining customer ordering, secure account management, and efficient delivery workflows. The prototype highlights user-friendly navigation, real-time order flow concepts, and automated notifications to support digital transformation and enhance service reliability.

Kavindu Grocery Data Science & Power BI Dashboard

Developed interactive Power BI dashboards for Kavindu Grocery, a local retail business, to analyze sales performance, product demand, and trends. The dashboards provide clear visual insights to support data-driven decision-making, improve inventory planning, and enhance overall business efficiency.

Doctor Channelling System

Developed a Java-based Doctor Channelling System to manage patient and doctor registrations, appointment booking, cancellations, and rescheduling. Implemented core data structures such as queues and stacks to handle appointment scheduling, waiting lists, and request management, ensuring efficient slot allocation and real-time patient notifications.
